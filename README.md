# Сайт студии MirrorMirage

Статический сайт для mirrormirage.ru, публикуется через GitHub Pages из ветки `main`.

- Страницы: `index.html`, `programs.html`, `services.html`, `about.html`, `contacts.html`, `404.html`
- Домен задаётся файлом `CNAME`
- Обновить сайт: изменить файлы и сделать `git push` в `main`, через 1–2 минуты изменения появятся на сайте
